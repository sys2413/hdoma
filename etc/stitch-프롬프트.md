## 1) 첫 화면

```
한국의 훈연 고기 전문점 '훈연도마'의 홈페이지 첫 화면을 디자인해줘.

[가게 성격]
소고기 양지를 42시간(건염 24시간 + 훈연 14시간 + 레스팅 4시간) 준비해서,
손님 바로 앞 나무도마 위에서 직접 썰어 내는 가게.
고기 굽는 냄새가 나지 않는, 오마카세 다이닝처럼 조용하고 깔끔한 분위기.
흔한 고기집 느낌(붉은 조명, 자욱한 연기, 불판 사진, 두꺼운 붓글씨)은 절대 쓰지 말 것.

[색 - 정확히 이 값으로]
배경 #EDEAE5 (밝은 회색 콘크리트 벽)
강조 #9C3D14 (훈연 불씨색, 강조는 이 색 하나만)
보조 #B0794A (나무도마색)
어두운 구간 배경 #2E2A26
본문 글자 #201E1B
구분선 #D6D1C9

[글꼴]
한글 지원 폰트. 제목은 굵고 존재감 있게, 본문은 가볍고 여백을 넉넉히.
숫자 '42'가 화면에서 가장 강하게 보여야 함.

[구성 - 위에서 아래로]
1. 상단 고정 내비게이션: 왼쪽 로고 '훈연도마', 오른쪽 메뉴(첫 화면 / 메뉴판 / 소식받기), 맨 오른쪽 다크모드 버튼
2. 히어로: 왼쪽에 가게 이름 '훈연도마'를 아주 크게, 아래 한 줄 소개 "42시간을 기다린 고기를 눈앞에서 썰어드리는, 고기 냄새는 나지 않는 고기집", 버튼 2개(전체 메뉴 보기 / 영업시간·찾아오는 길). 오른쪽에 나무도마 위 썰린 고기와 칼, 위로 피어오르는 연기
3. 어두운 가로 띠(#2E2A26): 왼쪽에 '42 HOURS'를 거대하게, 오른쪽에 건염 24시간 / 훈연 14시간 / 레스팅 4시간 3칸
4. 시작 이야기: 왼쪽 본문 두 문단, 오른쪽에 큰 인용문 "이 가게가 파는 것은 고기가 아니라 그 표정입니다"
5. 저녁 8시 장면: 단골 이야기 한 단락, 그 아래 가운데 정렬로 아주 큰 문장 "자, 먹으면 더 놀랍니다~"
6. 공간: 보이는 것 / 조명 / 냄새 / 소리 4칸 카드, 각각 얇은 선 아이콘
7. 어두운 구간 '우리가 안 하는 것': 왼쪽에 큰 인용 "고기가 무제한 나오는 것보다, 질 좋은 고기가 저희 가게의 자신감입니다", 오른쪽에 항목 3개
8. 대표 메뉴 3장 카드: 브리스킷 / 비프립 / 번트엔드 — 설명, 준비 시간, 가격
9. 푸터: 영업시간 17:00–23:00(라스트오더 22:00), 매주 월요일 휴무, 주소, 전화, 인스타그램

[스타일]
모서리는 각지게(둥근 모서리 최소화), 그림자는 거의 없이, 여백을 크게.
데스크톱과 모바일 둘 다.
```

## 2) 메뉴판

```
같은 '훈연도마' 사이트의 메뉴판 페이지를 디자인해줘.
색, 글꼴, 상단 내비게이션은 첫 화면과 똑같이 유지할 것.

[구성 - 위에서 아래로]
1. 페이지 머리: '← 첫 화면으로' 링크, 제목 '전체 메뉴', 그 아래 두 라인 안내 카드 2개
   - LINE 01 훈연 — 사장이 썰어서 냅니다
   - LINE 02 직화 — 손님이 직접 구우십니다
2. 어두운 가로 띠(#2E2A26): '42 HOURS'와 건염/훈연/레스팅 3단계
3. 대표 메뉴 3가지 — 카드가 아니라 한 메뉴가 가로 한 줄을 통째로 쓰는 큰 배치.
   왼쪽에 메뉴명(아주 크게)과 설명, 그 아래 회색 박스 안에 사연 한 단락,
   준비 시간을 알약 모양 태그로, 오른쪽 끝에 세로선과 함께 가격
   - 브리스킷 (200g 38,000 / 400g 72,000)
   - 비프립 (1대 약 500g, 89,000)
   - 번트엔드 (150g 24,000)
4. 나머지 메뉴 가격표: '직화'와 '곁들임·식사' 두 그룹으로 나눈 표
   채끝 42,000 / 살치살 39,000 / 삼겹살 18,000 / 훈연 육수 냉면 11,000 / 구운 야채 9,000 / 공기밥 2,000
5. 사장님 추천 조합 — 이 구간만 배경을 어둡게(#2E2A26) 반전시켜서 페이지에서 가장 눈에 띄게.
   카드 3장, 그중 첫 번째는 더 넓고 불씨색 테두리에 '추천' 배지를 달 것
6. '주문 전에 하나만' 안내 3가지
7. 아래쪽에 '← 첫 화면으로 돌아가기'와 '소식받기 →' 버튼
8. 첫 화면과 동일한 푸터
```

## 3) 소식받기

```
같은 '훈연도마' 사이트의 소식 구독 신청 페이지를 디자인해줘.
색, 글꼴, 상단 내비게이션은 첫 화면과 똑같이 유지할 것.

[구성 - 위에서 아래로]
1. 페이지 머리: '← 첫 화면으로' 링크, 제목 '소식받기',
   부제 "자주 보내지는 않습니다. 알려드릴 게 생겼을 때만, 조용히 한 통 보내드릴게요."
2. 보내는 소식 4칸 카드(얇은 선 아이콘): 새 고기 / 훈연 클래스 / 이벤트 / 오늘의 안내
3. 실제 발송 예시 4개 — 왼쪽에 굵은 세로선이 있는 인용 박스 형태
   예) "오늘 브리스킷은 다 나갔습니다. 내일은 조금 더 넉넉히 준비해두겠습니다."
4. 점선 테두리 박스 '이런 건 보내지 않습니다': 광고성 느낌표, "역대급" 같은 표현, "마감 임박" 같은 재촉
5. 신청 구간 — 배경을 어둡게(#2E2A26) 반전.
   이름 입력칸, 이메일 입력칸, 받고 싶은 소식 선택 알약 버튼 4개,
   그 아래 불씨색 큰 신청 버튼 '소식 받아볼게요'
6. 신청 완료 화면도 함께: 동그란 체크 표시, "○○님, 고맙습니다~",
   그 아래 안내 문단과 마지막 줄 "자, 먹으면 더 놀랍니다~"
7. 첫 화면과 동일한 푸터
```

## 넣을 때 요령

- 입력창 위 **웹** 선택 확인 (앱 아님)
- 팔레트 아이콘(🎨)에서 색과 글꼴을 직접 지정할 수 있음 → 위 hex 값을 여기에도 넣어두면 더 잘 지켜짐
- 모델은 Flash보다 상위 모델이 선택 가능하면 그쪽이 결과가 낫습니다
- 첫 결과가 마음에 안 들면 새로 쓰지 말고 이어서 고쳐달라고 하세요
  - "고기집 느낌이 너무 강해. 더 조용하고 갤러리 같은 분위기로."
  - "42라는 숫자를 두 배로 키워줘."
  - "카드 모서리를 각지게 해줘."
  - "강조색을 #9C3D14 하나만 써줘."
